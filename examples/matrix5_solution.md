# Подробное умножение двух матриц 5×5

Числа выбраны произвольно и зафиксированы. Все вычисления целочисленные.

A
```
   2   -1    3    0    4
   1    5   -2    3    1
   0    2    4   -1    3
   3    1    0    2   -2
  -1    4    2    1    5
```

B
```
   1    3   -1    2    0
   2   -2    4    1    3
  -1    0    2    5    1
   4    1    0   -2    2
   3    2    1    0   -1
```

C = AB
```
   9   16    4   18   -4
  28   -2   16   -9   18
   5    1   19   24    5
   7    5   -1    3    9
  24    0   26   10   11
```

Правило: c[i,j] = сумма A[i,k] × B[k,j] по k от 1 до 5.
В каждой ячейке выполняем 5 умножений и 4 сложения; s[k] — накопленная сумма.

Всего 125 умножений, 100 сложений; все 25 элементов и промежуточные результаты проверены SymPy.

## Элемент c[1,1] = 9

Берём строку 1 матрицы A: `[2, -1, 3, 0, 4]` и столбец 1 матрицы B: `[1, 2, -1, 4, 3]`.

1. 2 × 1 = 2; начальная сумма s[1] = 2.
2. (-1) × 2 = -2; s[2] = 2 + (-2) = 0.
3. 3 × (-1) = -3; s[3] = 0 + (-3) = -3.
4. 0 × 4 = 0; s[4] = (-3) + 0 = -3.
5. 4 × 3 = 12; s[5] = (-3) + 12 = 9.

Итог: **c[1,1] = 9**.
